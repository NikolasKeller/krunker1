The HUD and menus use **Squada One**, by Admix Designs. The font is
bundled locally and preloaded; gameplay makes no request to a font CDN.

- Source: https://github.com/google/fonts/tree/main/ofl/squadaone
- Original file: `SquadaOne-Regular.ttf` (unmodified, renamed `squada-one.ttf`)
- License: SIL Open Font License 1.1, included in `squada-one-OFL.txt`.

Its heavy, compact letters and rounded rectangular counters are closer to the
supplied gameplay reference than Lilita One's wide, soft shapes. Squada One was
compared with Lilita One, Jersey 20/25, Jaro and Anton using rendered specimens
beside crops of the reference. Native specimens establish the font choice;
browser screenshots must still verify the final layout.

The font is 19,072 bytes (Lilita One was 28,092 bytes). Existing Lilita One, Teko
and Barlow files are retained for previously cached builds but are not loaded by
the current stylesheet.
