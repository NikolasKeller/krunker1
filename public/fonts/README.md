The HUD and menus use **Lilita One**, designed by Juan Montoreano. The font is
bundled locally and preloaded; gameplay makes no request to a font CDN.

- Source: https://github.com/google/fonts/tree/main/ofl/lilitaone
- Original file: `LilitaOne-Regular.ttf` (unmodified, renamed `lilita-one.ttf`)
- License: SIL Open Font License 1.1, included in `lilita-one-OFL.txt`.

Its rounded, heavy letterforms replace the narrow Teko face. Existing Teko and
Barlow files are retained for compatibility with previously cached builds.
